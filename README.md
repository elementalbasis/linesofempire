# Lines of Empire

Intended to be an improved clone of the mobile game "European War 3". That game
only allows you to move pieces within certain limited theaters, such as Europe
or East Asia. But I want Lines of Empire to allow you to move pieces across the
entire globe. What's more, most games that simulate the whole world do not use a
true globe, but merely a flat representation of it. Therefore, Lines of Empire
will use a true globe.
